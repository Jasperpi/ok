# Every mark the sheet knows

A paragraph is plain ink. *Emphasis* is an underscore struck under the letters, **strong** is a double strike, and ***both*** are both. A `code span` is shown as typed, and so is an address such as https://example.com/orchard.

## A second-level heading is double struck

### A third-level heading is plain

- A list item whose words run on long enough to wrap, so that the second row can be seen to hang under the first letter of the item and not under its marker
- [ ] A box, shown as typed
- [x] And one that is done
  - An item nested by two spaces
